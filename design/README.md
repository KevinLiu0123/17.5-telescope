# 設計檔

17.5 吋牛頓反射式望遠鏡的 CAD 設計檔。在 GitHub 上點開 `.stl` 檔可以直接 3D 旋轉檢視；同一個檔案改版後，GitHub 也能比對新舊版本的差異。

## 資料夾

| 位置 | 內容 |
|---|---|
| `OTA_assembly.stl` | 整支鏡筒組合 |
| `parts/` | 各零件的 STL／STEP，給加工廠用 |
| `drawings/` | 2D 加工圖（PDF） |

## 改版紀錄

每次更新設計檔，在最上面加一行：日期、誰、改了什麼、為什麼。

| 日期 | 誰 | 改了什麼 | 為什麼 |
|---|---|---|---|
| 2026-11-21 | | 上傳整支鏡筒組合 `OTA_assembly.stl` | 初版設計完成 |

## 注意

- 單檔上限 100 MB（用 GitHub Desktop 上傳）；GitHub 網頁上傳上限 25 MB。
- Fusion 360 原始檔（`.f3d`）可放進來備份，但 GitHub 無法預覽內容。
- 這個資料夾會跟網站一起公開。
